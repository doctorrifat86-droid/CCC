# CCC — Critical Care Center (ICU companion app)

Offline Android app for ICU teams: ward board with NEWS2, CMH-style 24-hour observation chart, intake/output balance, FAST HUG, critical event flow sheet, medication administration record, RASS / CAM-ICU / SOFA, drip calculator with dose warnings, ABG, ventilation and electrolyte tools, and searchable ACE Critical Care Protocols (52 flowcharts).

## Install
1. Download **[CCC.apk](https://github.com/doctorrifat86-droid/CCC/releases/latest/download/CCC.apk)** on your Android phone or tablet (Android 7+).
2. Open it from Downloads and allow "Install unknown apps" if asked.

All data stays on the device. No internet needed.

> **Training and teaching tool only. Not a medical device. Verify all doses and decisions clinically.**
